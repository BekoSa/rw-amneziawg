# Терминальное управление (TUI)

Веб-интерфейса управления у расширения нет. Администрирование — терминальное приложение (Textual),
которое запускается в контейнере во внутренней сети расширения и говорит только с Controller API.
Ни один порт управления не публикуется.

```sh
/opt/awg-extension/awg            # интерфейс
/opt/awg-extension/awg status     # ноды и ревизии одной строкой
/opt/awg-extension/awg peers      # пользователи, IP, трафик
/opt/awg-extension/awg reconcile  # немедленная синхронизация с Remnawave
```

В лаборатории: `scripts/lab.sh tui` (и `scripts/lab.sh tui status`).

## Вкладки и клавиши

| Вкладка | Что видно | Действия |
|---|---|---|
| Обзор | ноды READY, профили, активные пользователи AWG, суммарный трафик | — |
| Ноды | online/offline, состояние, applied/desired ревизия, порт, последняя связь | `n` — выпустить ключ новой ноды и получить команду установки; «Нода установлена — подключить» |
| Профили | версия AWG, endpoint, pool, число squads, статус (черновик / проверен / применён) | `n` — создать, `e` — изменить |
| Пользователи | имя, состояние (активен / отключён / лимит / истёк срок / нет доступа / удаляется с ноды), IP, handshake, ↑ upload / ↓ download | `k` — сменить ключ пользователя; фильтр по имени/IP |
| Ошибки | ошибки reconcile и применения | — |

Общие клавиши: `r` — обновить, `s` — синхронизировать с Remnawave, `q` — выход.

## Профиль: Save → Validate → Apply

UDP-порт подставляется сам — тот, что открыл на ноде `install-node.sh` (случайный); Validate отклоняет порт,
который на ноде не открыт. В редакторе выбираются нода, endpoint, pool, DNS, Internal Squads Remnawave (по именам, из API) и
версия AmneziaWG. Новый профиль по умолчанию — **AWG 3.1** со сгенерированными параметрами
(«Сгенерировать параметры» выдаёт новые валидные значения, включая `HeaderProtectionKey`).

1. **Сохранить черновик** — работающий туннель не меняется.
2. **Проверить** — Agent компилирует конфиг и проверяет его против своих возможностей.
3. **Применить** — доступно только после успешной проверки именно этого черновика; любое изменение
   полей снова блокирует кнопку.

## Новая нода

1. `Ноды → n`: название и адрес ноды. TUI выпускает сертификат ноды, подписанный CA расширения, и
   показывает команду `sudo ./install-node.sh` и ключ `awgnode1:…` — его вставляют, когда установщик
   спросит (в командную строку ключ не попадает). Ключ показывается один раз.
2. На VPN-сервере выполнить команду из каталога проекта (см. [установку](../deploy/production/README.md)).
3. В TUI нажать «Нода установлена — подключить». Окно можно закрыть на время установки: потом снова
   `Ноды → n`, ввести название, адрес и **ID ноды** (его печатает `install-node.sh`) и нажать «Подключить».

Доступ пользователей по-прежнему выдаётся в Remnawave: пользователь в выбранном squad получает AWG.
